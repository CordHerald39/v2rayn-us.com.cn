## 三项信息决定下载选择

先确认操作系统、处理器架构以及希望采用便携包还是系统安装包。本页按 7.24.9 发行资产举例；官方下载见[下载中心](/downloads/)，最低系统要求以开发者文档为准。

| 平台 | 选择顺序 | 常见误区 |
| --- | --- | --- |
| Windows | 64 / 86 / arm64，再看是否 desktop | 64 位系统不应随意拿 ARM64 包 |
| macOS | Intel 对应 64，Apple Silicon 对应 arm64 | 不能仅因扩展名都是 DMG 就认为相同 |
| Linux | CPU 架构，再按发行版选择 deb / rpm / ZIP | 同架构不代表不同包管理格式通用 |

## Windows 两类界面

开发者文件说明区分 WPF 与 desktop（Avalonia）界面。不要把 desktop 误解成“只有这个包才能在电脑运行”。先选择符合设备与需求的一个版本，不把两套文件混合覆盖到一个目录。

## ZIP 与安装包的维护差异

便携 ZIP 应完整解压到可写目录，保留文件结构。系统安装包的数据位置可能跟随系统规范，不能只备份桌面快捷方式。安装或迁移前查明真实配置位置，再保存可恢复副本。

## 签名和源码不是应用

同名 .sig 用于签名核验，公钥用于核对发布身份；Source code 是源码。下载详情页列出的是客户端包，校验时仍要回同一个固定版本发行页找对应材料。

核对到 7.24.9 发行说明含旧版内置下载器的安全修复信息。升级决策应阅读原说明并备份，不应单靠“旧版能启动”长期忽略发布者的安全提示。
