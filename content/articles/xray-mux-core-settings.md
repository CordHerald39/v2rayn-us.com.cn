## 新界面项解决的是参数编辑
7.25.4 加入核心设置中的 Mux 配置。官方 PR #10055 说明，新界面暴露 Xray 的 TCP 并发、XUDP 并发以及 UDP/443 的相关行为，并继续保留配置级启用和能力判断。出现了参数输入框，并不证明当前节点已经启用了 Mux。

## 从当前配置的能力开始
先确定所用核心、协议和传输组合，再看该配置的 Mux 开关。PR 明确保留了不支持场景的禁用逻辑，例如 VLESS Reality Vision。遇到这一类配置，不应因为界面可编辑并发数就期待生成配置启用多路复用。
sing-box 另有自身的多路复用协议选择，不能把 Xray 的并发项直接当作通用跨核心参数。本页关注新增的 Xray 设置入口，不给出适用于所有核心的“最快数值”。

## 做一次只改一个参数的比较
记录原来的启用状态、并发值、目标任务和网络环境。在确认受支持后，只修改一个参数，重新建立连接，用相同任务对照请求成功率与响应。短网页、大文件和实时应用的表现可能不同，不能用一项延迟数字替代全部体验。
若出现新失败，先恢复原值和启用状态，再核对日志中是否存在不兼容或连接错误。UDP/443 行为的变化应另外记录，避免把它与 TCP 并发一起改变而无法区分原因。

## 什么结果值得保留
| 记录 | 用途 |
| --- | --- |
| 核心与节点组合 | 判断配置是否支持 |
| 改动前后值 | 能够恢复并重做比较 |
| 任务与失败情况 | 避免只选择有利读数 |
| 日志中的生成与启动结果 | 确认设置真正进入运行路径 |
PR 作者报告的测试只属于上游提交，不能当作本站或你的设备实测。我们未执行 GUI 或吞吐测试，也不声称 Mux 一定提速。已有稳定配置可以保留原值，只有明确需求时再做对照。
