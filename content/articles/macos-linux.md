## macOS 先确定处理器

Intel 与 Apple Silicon 应选择对应资产。当前固定版本提供 64 与 arm64 的 DMG 和 ZIP，下载前核对开发者最低系统要求。不要把其他教程中的安装包名直接套到当前版本。

遇到系统安全提示时先确认文件来源、签名说明及完整性，不从不明网站复制批量解除安全标记的命令。具体安装权限与提示取决于系统版本，本指南没有 macOS 实机结果。

## Linux 同时看架构和发行版

deb 与 rpm 面向不同包管理体系；便携 ZIP 的运行和存储方式也不同。查看当前系统信息，再对照[下载详情](/software/linux/)的附件，不把 WSL、容器与完整桌面环境视作同一运行条件。

开发者说明提到 ZIP 解压后的执行权限要求。修改权限前先确认对象是从原始渠道获取的程序，不用管理员权限盲目运行整个下载目录。

## 数据与权限分开核验

便携包与系统安装包可能使用不同数据目录。先找到真实配置位置并备份，再更新软件。程序能显示窗口与系统代理被应用采用是两件事，还需在目标应用检查新请求。

反馈安装问题时提供发行版或 macOS 版本、CPU、完整附件名、启动错误；连接问题另附接管方式和日志。不要只提交“Linux 不能用”。
